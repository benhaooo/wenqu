# 安全规范

## 密钥管理

数据库密码、第三方 API Key 等密钥只能通过环境变量注入，禁止写进代码仓库。生产环境的密钥由运维在部署平台的密钥管理中配置，开发人员没有生产密钥的访问权限。

## XSS 防护

渲染用户输入或 AI 生成的内容时禁止使用 `dangerouslySetInnerHTML`，确实需要渲染 HTML 时必须先经过白名单净化。富文本内容在后端保存前会再次净化，去掉脚本和事件属性。

## 权限校验

前端隐藏按钮只是体验优化，所有权限必须在后端校验。访问不属于自己的空间时，接口返回 404 而不是 403，避免泄露资源是否存在。

## 依赖安全

每月检查一次依赖漏洞，高危漏洞需要在一周内升级修复。
