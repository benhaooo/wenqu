# 本地开发环境

## 准备工作

需要安装 JDK 21、Node.js 22、pnpm 10 和 Docker Desktop。克隆仓库后在根目录执行 `make setup`，它会安装依赖、配置 Git 钩子并从 `.env.example` 生成 `.env`。

## 启动依赖

执行 `make deps` 启动 PostgreSQL、Redis、RabbitMQ 和 MinIO 四个 Docker 容器。

## 启动服务

分别在两个终端执行 `make dev-backend` 和 `make dev-frontend`。后端默认端口 8080，前端默认端口 5173，前端开发服务器会把 `/api` 请求代理到后端。

## 常见问题

如果端口被占用，在 `.env` 中修改 `BACKEND_PORT` 或 `FRONTEND_PORT`。数据库结构出问题时执行 `make db-reset` 清空本地数据库，后端启动时会重新执行迁移脚本。
