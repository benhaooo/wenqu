# 前端架构说明

## 技术栈

前端使用 React 19、TypeScript 和 Vite 构建，样式使用 Tailwind CSS，组件库基于 shadcn/ui。

## 状态管理

服务端数据统一由 TanStack Query 管理，包括缓存、重试和后台刷新；Zustand 只保存客户端状态，例如当前登录态和界面开关。不要把接口返回的数据复制到 Zustand 中。

## 请求层

所有接口请求经过统一的 http 函数。Access Token 过期时，请求拦截器只发起一次刷新，期间的其他请求排队等待，刷新成功后统一重放；多个浏览器标签页之间使用 Web Locks 串行刷新，避免同时使用同一个 Refresh Token。

## 接口类型

前端不手写接口类型，类型和请求 hooks 由后端导出的 openapi.json 通过 orval 自动生成，执行 `make api` 更新。

## 目录结构

代码按业务功能划分在 features 目录下，功能之间只能通过各自的 index.ts 引用，这条规则由 ESLint 检查。
